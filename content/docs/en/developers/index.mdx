This section documents project governance roles and the public roster. Lattice Hub is still early; the Maintainer and Committer roles are currently held by the same core contributor.

## Roles

| Role | Responsibility |
| --- | --- |
| Maintainer | Owns project direction, release cadence, critical change review, and community norms |
| Committer | Has write access and can review and merge contributions that meet project standards |

## Current roster

- [Maintainers](/en/docs/developers/maintainers): people who steward the project
- [Committers](/en/docs/developers/committers): contributors with commit access

## How to contribute

Open issues and pull requests in the [Lattice Hub organization](https://github.com/lattice-hub). Sustained, high-quality contributions can lead to Committer nomination. Committers who take ongoing responsibility for architecture and releases may become Maintainers.
