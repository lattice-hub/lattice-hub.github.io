Thin SDK is the multi-language access layer for **Pole Sidecar**. Unlike the Proxyless [Rust SDK](/en/docs/components/rust-sdk), applications do not talk to the control plane for full in-process governance. They open a local Sidecar Session, receive listener snapshots, and inject `TargetService v1` metadata so the Sidecar can govern and forward traffic.

## Contract

The contract source lives in [specification / thin-sdk](https://github.com/lattice-hub/specification/tree/main/thin-sdk). Current contract version is `2.0.0`:

- Sidecar Session wire v1
- TargetService wire v1 (`namespace` + `service` only)

Legacy `TargetEnvelope v1` (contract `1.0.0`) is deprecated. Default bootstrap UDS: `/var/run/pole/sidecar/bootstrap.sock`, overridable with `POLE_SIDECAR_SOCKET`.

## Capability boundary

- Ships framework-independent contract cores: open Sidecar Session, receive listener snapshots, encode TargetService metadata
- No HTTP / gRPC / Dubbo framework adapters
- Business traffic still uses the original protocol against `127.0.0.1:<listener-port>`—not the bootstrap gRPC session
- End-to-end compatibility still follows the [compatibility matrix](https://github.com/lattice-hub/specification/blob/main/thin-sdk/compatibility.json); docs must **not** claim production readiness
