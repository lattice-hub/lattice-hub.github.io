Reports only present confirmed facts, reproducible experiments, and explicitly planned measurements.

## Current reports

- [Performance data report](/en/docs/reports/performance): confirmed configuration facts, observation dimensions, and planned benchmarks.

## Writing rules

- No unsourced performance metrics.
- No marketing claims like “10x faster” or “99.9% uptime”.
- Mark missing data as “planned / not yet measured”.
- Default configuration values may appear, but must be labeled as configuration facts—not benchmark results.
