## Conventions

| Item | Notes |
| --- | --- |
| Base URL | `http://127.0.0.1:8090` |
| Management auth | `Authorization` + `X-Pole-User` |
| Group switches | `api-http.api.{console,client,admin,aimcp,aia2a}` |

Full schemas follow control-plane annotations and the running server.
