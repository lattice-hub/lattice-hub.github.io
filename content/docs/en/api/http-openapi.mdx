The HTTP API is served by the `api-http` plugin on port **8090**. Each endpoint below shows **parameters** beside **multi-language request samples**. Full schemas still follow control-plane annotations in `plugin/apiserver/httpserver/docs/*_apidoc.go` and the running server.

Do not confuse this with **OpenAPI 3.x service contracts** that business services may report—that is a discovery/service-contract feature, not the control-plane REST surface.

## Conventions

| Item | Notes |
| --- | --- |
| Base URL | `http://127.0.0.1:8090` (replace per deployment) |
| Management auth | `Authorization: <token>` + `X-Pole-User: <user_id>` from login |
| API group switches | `pole-apiserver.yaml` → `api-http.api.{console,client,admin,aimcp,aia2a}` |
| Preferred client path | Prefer gRPC `8091` / `8093` for discover/register; HTTP is for scripts and debugging |

Path prefixes: `/auth/v1`, `/core/v1`, `/naming/v1`, `/config/v1`, `/admin/v1`, `/ai/mcp/v1`, `/ai/a2a/v1`, plus client-group `/v1/*`.
