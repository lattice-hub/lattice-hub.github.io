Menus: **AI tools → MCP services**, **A2A Agent**; Agent via mode switch to `/agent` (not in the sidebar).

## MCP services

Path: `/ai/mcps`, header “MCP services”.

### List actions

1. Filter by namespace and protocol; search by name.
2. “Create MCP Server”.
3. Inspect summary metrics: Servers / Namespaces / HTTP / SSE·Stream / Pole services, and so on.
4. Open detail for tools; authorize; jump to the linked backend service.

### Common create fields

Name, namespace, business, department, linked service or custom address, protocol, port, visible namespaces, backend type, description, and similar.

After changes, confirm cache refresh so list and detail agree; grant callers least-privilege read. See [Authorization](/en/docs/guides/console/authorization).

![MCP Registry](/images/console/mcp-registry.png)

## A2A Agent

Path: `/ai/a2a`, header “A2A Agent”.

### Create wizard tabs

1. **Basics**: name, namespace, version, protocol version, business, department, description, provider, docs/icon, and so on
2. **Access and capabilities**: preferred protocol/address, backend binding, Streaming / Push / Extended Card toggles
3. **Skills**: maintain the skill list
4. **Source and Card**: Agent Card metadata

### Detail tabs

**Agent Card** / **Skills** / **Edit**. List and detail both support resource authorization.

![A2A Registry](/images/console/a2a-registry.png)

**Boundary:** A2A registers Card, skills, and protocol metadata only—it is not a task agent or Agent Runtime.

## Pole Agent workspace

### How to enter

1. In the normal Console, use the Workspace mode switch: “Enter Agent workspace”.
2. Or click “Hand to Agent” on a config file (carries namespace/group/name context).
3. Return with “Back to normal Console”.

There is no persistent “Agent” sidebar item.

![Pole Agent workspace](/images/console/agent.png)

### Steps

1. Create or select a session (search; groups “Today / Yesterday / Earlier”).
2. Ask for a read-only query or a config-change intent.
3. Writes first show a change preview (“Awaiting confirmation”).
4. After confirm, status becomes “Saved as draft”—**no publish version, no immediate effect**.
5. Return to [Configuration](/en/docs/guides/console/configuration) and publish that file.

On-screen safety copy states writes preview first, confirm saves drafts only, Enter sends / Shift+Enter newline, and writes do not publish resources directly.

### Prerequisites and limits

- Configure LLM Gateway / API keys under [System configuration](/en/docs/guides/console/system) or the entry stays unavailable.
- Write path today mainly covers **updates to existing config files**; governance writes are still evolving.
- MCP tools outside the whitelist are not callable by Agent.
