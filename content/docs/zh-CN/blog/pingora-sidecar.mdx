Pole Sidecar 选择 Pingora，是为了在不强迫所有语言接入 SDK 的情况下，仍能消费 Lattice Hub 的发现与治理语义。

## 路线定位

- 本地执行：HTTP/gRPC 转发、路由匹配、负载均衡与拦截器扩展。
- 控制面掌事实：服务、配置、active 治理规则仍由 Lattice Hub 发布。
- 与 SDK 并存：Rust 等语言可 Proxyless；多语言或低侵入场景用 Sidecar。

## 当前骨架

- TOML 配置路由与上游集群
- `grpc_prefix` 优先于 `prefix`
- round_robin 负载均衡示例
- 请求/上游阶段拦截器回调占位

## 下一步

把拦截器接到真实限流、熔断、鉴权与指标，并与 Controller 注入（`dns` / `mesh`）打通生产路径。在此之前，先完成“能转、能观测、能对齐控制面版本”的闭环。
