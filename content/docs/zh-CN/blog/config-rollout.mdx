配置中心不仅是键值存储。它需要支持发布、灰度、回滚和监听，让应用在配置变化时以可控方式感知更新。

## 已确认事实

- 配置内容最大 20,000 字符。
- 最大分页 100。
- 支持发布、灰度、回滚。
- **同一配置文件可同时存在多条 active 灰度版本**；全量发布不结束这些灰度；停灰度按单条操作。
- 客户端同时命中多条灰度时，按 version / mtime 选择最新一条。
- 支持 SSE 或长轮询监听。
- 编辑态与发布态分离：客户端消费的是发布结果。
- Pole Agent 确认后的写操作只保存草稿，发布仍由配置中心完成。

## 推荐操作节奏

1. 在正确 Namespace 创建分组与文件。
2. 编辑草稿并完成内容校验。
3. 按客户端标签发布一条或多条灰度，在「发布记录 → 灰度发布」与订阅查询中观察命中。
4. 确认后对目标灰度「提交为正式草稿」再全量；其它灰度可继续保留或单独停止。
5. 异常时回滚全量或停止相关灰度；在 History 中核对操作记录。

## 监听侧注意点

- 客户端应基于版本/revision 判断是否应用新配置。
- 回滚也是一次新的发布决策，历史版本应仍可追溯。
- 超大配置应拆分，避免触达 20,000 字符上限。
