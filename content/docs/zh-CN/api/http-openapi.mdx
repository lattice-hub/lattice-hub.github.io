HTTP API 由 `api-http` 插件提供，默认监听 **8090**。下面按接口展示**参数说明**与**多语言请求示例**；完整 schema 仍以控制面注解 `plugin/apiserver/httpserver/docs/*_apidoc.go` 与运行时为准。

不要与「业务服务上报的 OpenAPI 3.x 契约」混淆——那是发现域的服务契约能力，不是本页描述的控制面 REST。

## 使用约定

| 项 | 说明 |
| --- | --- |
| Base URL | `http://127.0.0.1:8090`（按部署替换） |
| 管理面鉴权 | `Authorization: <token>` + `X-Pole-User: <user_id>`，来自登录接口 |
| API 分组开关 | `pole-apiserver.yaml` → `api-http.api.{console,client,admin,aimcp,aia2a}` |
| 客户端主路径 | 发现/注册更推荐 gRPC `8091` / `8093`；HTTP 便于脚本与联调 |

路径前缀速查：`/auth/v1`、`/core/v1`、`/naming/v1`、`/config/v1`、`/admin/v1`、`/ai/mcp/v1`、`/ai/a2a/v1`，以及 client 分组下的 `/v1/*`。
