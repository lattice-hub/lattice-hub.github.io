## 使用约定

| 项 | 说明 |
| --- | --- |
| Base URL | `http://127.0.0.1:8090` |
| 管理面鉴权 | `Authorization`（登录返回的 token） |
| 分组开关 | `api-http.api.{console,client,admin,aimcp,aia2a}` |

完整 schema 以控制面注解与运行时为准。
