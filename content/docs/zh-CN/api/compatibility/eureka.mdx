插件：`service-eureka`。默认端口：**8761**。前缀 `/eureka`、`/eureka/v1`、`/eureka/v2` 挂载**同一套**路由（任选其一；下文以 `/eureka` 为例）。

Accept / Content-Type 支持 JSON 与 XML。`appId` 路径参数会规范为大写。可用请求头 `x-namespace` 覆盖默认命名空间（未传则用插件配置 `namespace`，常见为 `default`）。

## 接口列表

下列路径在 `/eureka`、`/eureka/v1`、`/eureka/v2` 下各有一份。

| Method | Path | 说明 |
| --- | --- | --- |
| `POST` | `/eureka/apps/{appId}` | 注册实例 |
| `DELETE` | `/eureka/apps/{appId}/{instId}` | 反注册 |
| `PUT` | `/eureka/apps/{appId}/{instId}` | 心跳 |
| `GET` | `/eureka/apps` | 全量应用列表 |
| `GET` | `/eureka/apps/delta` | 增量应用列表 |
| `GET` | `/eureka/apps/{appId}` | 查询单应用 |
| `GET` | `/eureka/apps/{appId}/{instId}` | 查询应用下实例 |
| `PUT` | `/eureka/apps/{appId}/{instId}/status?value=` | 更新状态（`UP` / `DOWN` / `OUT_OF_SERVICE` 等） |
| `DELETE` | `/eureka/apps/{appId}/{instId}/status` | 清除 override，恢复 `UP` |
| `GET` | `/eureka/instances/{instId}` | 按实例 ID 查询 |
| `PUT` | `/eureka/apps/{appId}/{instId}/metadata` | 更新 metadata（query 全量作 KV） |
| `GET` | `/eureka/vips/{vipAddress}` | VIP 查询 |
| `GET` | `/eureka/svips/{svipAddress}` | Secure VIP 查询 |
| `POST` | `/eureka/peerreplication/batch` | Peer 批量复制 |

## 鉴权

注册等写路径可带 Basic：`Authorization: Basic base64(user:token)`，取 `:` **后半段**作为控制面 token。读路径通常不强制。

## 调用示例

```bash
BASE=http://127.0.0.1:8761
TOKEN='<login-token>'
AUTH=$(printf 'user:%s' "$TOKEN" | base64)

# 注册（成功常见 204）
curl -i -X POST "$BASE/eureka/apps/ORDER" \
  -H 'Content-Type: application/json' \
  -H 'x-namespace: default' \
  -H "Authorization: Basic $AUTH" \
  -d '{
    "instance": {
      "instanceId": "i-1",
      "app": "ORDER",
      "ipAddr": "10.0.0.1",
      "hostName": "10.0.0.1",
      "status": "UP",
      "port": { "$": 8080, "@enabled": "true" },
      "dataCenterInfo": {
        "@class": "com.netflix.appinfo.InstanceInfo$DefaultDataCenterInfo",
        "name": "MyOwn"
      }
    }
  }'

# 心跳
curl -i -X PUT "$BASE/eureka/apps/ORDER/i-1" -H 'x-namespace: default'

# 全量 / 增量发现
curl -s "$BASE/eureka/apps" -H 'Accept: application/json'
curl -s "$BASE/eureka/apps/delta" -H 'Accept: application/json'

# 改状态 / 下线
curl -i -X PUT "$BASE/eureka/apps/ORDER/i-1/status?value=OUT_OF_SERVICE"
curl -i -X DELETE "$BASE/eureka/apps/ORDER/i-1"
```

## 边界

- 兼容 Eureka **注册发现客户端**常用路径，不是完整 Netflix Eureka Server（无原生仪表盘全量管理面）。
- 实例落入 Pole 服务/实例模型；Eureka 特有字段多进入内部 metadata。
- 自保护、peer 复制等行为与原生不完全等价。
