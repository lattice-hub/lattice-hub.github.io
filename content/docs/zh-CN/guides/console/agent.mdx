Pole Agent **不是**侧栏「AI 工具」下的菜单项。入口在侧栏底部独立卡片「进入 Agent 工作台」，路径 `/agent`。MCP / A2A Registry 见 [MCP 服务](/docs/guides/console/mcp) 与 [A2A Agent](/docs/guides/console/a2a)。

![Pole Agent 工作台](/images/console/agent.png)

## 如何进入 / 返回

1. 普通控制台侧栏底部点「进入 Agent 工作台」。
2. 或在配置文件页点「交给 Agent」（会带上 namespace/group/name 等上下文）。
3. 返回时选「返回普通控制台」。

侧栏不会常驻名为「Agent」的业务菜单；它是独立工作台模式。

## 使用步骤

1. 新建或选择会话（搜索会话；分组「今天 / 昨天 / 更早」）。
2. 提问或描述只读查询 / 配置修改意图。
3. 若产生写操作，先出现变更预览（「等待确认」）。
4. 确认后状态变为「已保存草稿」——**不会创建发布版本，不会立即生效**。
5. 回到 [配置中心](/docs/guides/console/configuration) 对该文件执行发布。

页面安全文案会明确：写操作先预览，确认后只保存草稿；Enter 发送 · Shift + Enter 换行；写操作不会直接发布资源。

## 前提与限制

- 需在 [系统配置](/docs/guides/console/system) 配好 LLM Gateway / API key 等 Agent 域配置，否则入口不可用。
- 当前写路径主要覆盖**已有配置文件更新**；治理规则写入等能力仍在演进。
- 未列入工具白名单的 MCP 工具不会被 Agent 调用（白名单工具仍需先在 [MCP 服务](/docs/guides/console/mcp) 登记）。
