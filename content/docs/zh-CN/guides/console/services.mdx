## 命名空间

路径：侧栏「命名空间」→ `/namespace`。

### 你能做什么

1. 查看列表与指标（命名空间数、服务数、配置文件数、健康实例等）。
2. 搜索命名空间名称。
3. **新建命名空间**：填写名称、描述、标签后提交。
4. **查看 / 编辑**：改描述与标签（名称创建后不可改）。
5. **授权**：打开资源授权抽屉，给主体配置该命名空间的访问范围。
6. **删除**：非保护命名空间可删（需权限）。

### 字段与约束

| 项 | 说明 |
| --- | --- |
| 名称 | 允许数字、英文字母、`.`、`-`、`_`，最长 128；创建后不可改 |
| 描述 | 建议写清环境用途或阶段，最长 1024 |
| 保护空间 | `default` 不可删；`pole-system`（内部系统空间）不可删 |

Namespace 表示**运行环境**，不是租户或团队空间。

## 服务列表

路径：侧栏「注册发现 → 服务实例」→ `/discovery/service`。

### 操作步骤

1. 用命名空间等条件定位服务。
2. 点「新建服务」，填写：
   - 身份：命名空间、服务名（创建后不可改）、描述
   - 归属：部门、业务
   - 服务标签
3. 提交后进入服务详情，或在列表点「查看编辑」。
4. 需要时删除服务（确认对话框「确认删除吗」）。

## 服务详情五个 Tab

进入服务后可见：

| Tab | 用途 |
| --- | --- |
| 服务详情 | 查看/编辑描述、部门、业务、标签；复制服务 ID |
| 服务实例 | 实例清单与健康检查 |
| 服务别名 | 跨命名空间访问别名 |
| 服务订阅 | 查看订阅方 / 被订阅关系 |
| 流量治理 | 嵌入治理工作台，按主调/被调筛选关联规则 |

页内还可能提供环境切换（同名服务跨 Namespace 跳转），操作前务必确认当前环境。

### 服务实例

1. 打开「服务实例」Tab，可按主机地址搜索。
2. 「新建实例」或编辑已有实例。
3. 关键字段：主机、端口（创建后编辑时只读）、协议（TCP/UDP/HTTP/gRPC/DUBBO）、版本、权重（0–100）、地理位置、实例标签。
4. 状态开关：隔离（开/关）、健康（健康/异常）、健康检查（开/关）。

**健康检查类型：**

| 类型 | 字段 | 注意 |
| --- | --- | --- |
| 心跳上报 | TTL（1–60 秒） | **创建实例时不可选**（仅后续编辑可用） |
| TCP 探测 | 探测间隔（1–60 秒） | |
| HTTP 探测 | 探测路径（如 `/health`）+ 探测间隔 | 路径必填 |

### 服务别名

1. 打开「服务别名」Tab → 创建别名。
2. 填写：目标服务、别名所在命名空间、别名、备注。
3. 别名规则：小写字母开头，仅小写字母/数字/中划线；同命名空间下不可重名。
4. 可查看、复制别名、删除。

### 服务订阅

只读查看谁订阅了该服务、该服务订阅了谁。空态为「暂无订阅关系」。用于理解调用拓扑，不在此页创建订阅。

## 文档边界

当前 Console **没有**独立的「服务契约」管理页面。契约相关能力若出现在权限策略资源类型中，不代表这里有契约 CRUD 界面。
