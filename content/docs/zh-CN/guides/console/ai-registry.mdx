对应菜单：**AI 工具 → MCP 服务**、**A2A Agent**；Agent 通过模式切换进入 `/agent`（不在侧栏菜单）。

## MCP 服务

路径：`/ai/mcps`，页头「MCP 服务」。

### 列表操作

1. 按命名空间、协议筛选；搜索服务名称。
2. 「新建 MCP Server」。
3. 查看指标：Servers / Namespaces / HTTP / SSE·Stream / Pole 服务等。
4. 进入详情管理工具列表；可授权；可跳转关联的后端服务。

### 创建时常见字段

名称、命名空间、业务、部门、关联服务或自定义地址、协议、端口、可见命名空间、后端类型、描述等。

操作后确认缓存刷新，列表与详情一致；给调用方最小读权限。见 [权限管理](/docs/guides/console/authorization)。

![MCP Registry](/images/console/mcp-registry.png)

## A2A Agent

路径：`/ai/a2a`，页头「A2A Agent」。

### 新建向导 Tabs

1. **基础信息**：名称、命名空间、版本、协议版本、业务、部门、描述、Provider、文档/图标等  
2. **接入与能力**：首选协议与地址、后端绑定、Streaming / Push / Extended Card 等开关  
3. **技能**：维护 Skill 列表  
4. **来源与 Card**：Agent Card 相关元数据  

### 详情 Tabs

**Agent Card** / **技能** / **编辑**。列表与详情均可做资源授权。

![A2A Registry](/images/console/a2a-registry.png)

**边界：** A2A 只登记 Card、技能与协议元数据，不负责任务代理或 Agent Runtime。

## Pole Agent 工作台

### 如何进入

1. 在普通控制台使用 Workspace 模式切换：「进入 Agent 工作台」。  
2. 或从配置文件页点「交给 Agent」（会带上 namespace/group/name 等上下文）。  
3. 返回时选「返回普通控制台」。

侧栏不会常驻「Agent」菜单项。

![Pole Agent 工作台](/images/console/agent.png)

### 使用步骤

1. 新建或选择会话（搜索会话；分组「今天 / 昨天 / 更早」）。
2. 提问或描述只读查询 / 配置修改意图。
3. 若产生写操作，先出现变更预览（「等待确认」）。
4. 确认后状态变为「已保存草稿」——**不会创建发布版本，不会立即生效**。
5. 回到 [配置中心](/docs/guides/console/configuration) 对该文件执行发布。

页面安全文案会明确：「写操作会先生成预览，确认后只保存为草稿」「Enter 发送 · Shift + Enter 换行 · 写操作不会直接发布资源」。

### 前提与限制

- 需在 [系统配置](/docs/guides/console/system) 配好 LLM Gateway / API key 等 Agent 域配置，否则入口不可用。
- 当前写路径主要覆盖**已有配置文件更新**；治理规则写入等能力仍在演进。
- 未列入工具白名单的 MCP 工具不会被 Agent 调用。
