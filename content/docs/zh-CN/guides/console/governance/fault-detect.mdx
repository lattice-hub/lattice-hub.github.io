---

向导类型：**探测**（`kind=faultdetect`）。保存成功 toast 称「主动探测规则」。

![主动探测编辑器](/images/console/gov-fault-detect.png)

## 操作步骤

1. 「新建规则」→「探测」。
2. 填写并保存：
   1. **基础信息**：规则名称（必填、kebab-case、≤64）、优先级、描述、规则标签
   2. **被探测对象**：被探测命名空间、被探测服务（必选）
   3. **探测规则**（至少 1 条）：
      - **基础调度**：协议 HTTP/TCP/UDP、启用/禁用、间隔秒 >0、超时秒 >0
      - **端口策略**：实例协议端口 / 指定探测端口（1–65535）
      - **载荷**：HTTP 方法 + URL（必填）+ Headers；或 TCP/UDP 发送/接收与匹配方式
3. 「发布」。

## HTTP / TCP / UDP

| 协议 | 关键字段 |
| --- | --- |
| HTTP | method、url、headers（key/value 均非空） |
| TCP / UDP | send、receive（receive 非空）；匹配：完全 / 包含 / 正则 |

## 发布与观察

- 发布资源：`FaultDetectRules`
- 常与熔断恢复中的「主动探测」开关配合使用，但本页规则独立维护
- 观察探测间隔与健康判定是否符合预期
