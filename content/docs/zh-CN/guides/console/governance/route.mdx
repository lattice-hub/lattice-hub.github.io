向导类型：**路由**（`kind=route`）。路径：`/governance/rules/create?kind=route&ruleNamespace=...`。

![路由规则编辑器](/images/console/gov-route.png)

## 操作步骤

1. 工作台「新建规则」→ 选归属环境 → 点「路由」。
2. 填写分区并保存：
   1. **基础信息**：规则名称（kebab-case）、优先级、状态（启用/停用）、描述、标签
   2. **服务范围**：主调命名空间/服务 → 被调命名空间/服务
   3. **路由规则**：添加子规则；每条子规则含匹配条件与目标分组
3. 退出编辑态后点「发布」，选全量或灰度。

也可从服务详情「流量治理」以主调/被调角色进入并关联规则。

## 匹配与目标分组

**匹配条件**常见参数类型：自定义、请求头、Cookie、请求参数、方法、主调 IP、路径。关系可选「全部满足 / 任一满足」。匹配值可为固定值或请求参数。

**目标分组**：

- 分组名称（自动 `Group N` 时可改）
- 隔离、权重、实例标签
- 同一子规则内权重合计必须 **= 100%**

## 校验要点

| 校验 | 说明 |
| --- | --- |
| 规则名称 | 必须 kebab-case |
| 权重 | 合计须 100%，否则保存失败 |
| 匹配值 | 不可为空 |
| 分组 | 不可存在未命名分组 |

## 发布与观察

- 发布资源类型：路由规则（`RouteRules`）。
- 发布后观察：流量是否落到预期版本/实例；灰度标签是否可收回。
- 回滚在详情「版本」Tab。
