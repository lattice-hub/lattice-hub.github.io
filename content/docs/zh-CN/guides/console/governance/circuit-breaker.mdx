title: 熔断规则
description: 配置熔断粒度、错误判断与触发条件、恢复策略与熔断后降级。
---

向导类型：**熔断**（`kind=circuitbreaker`）。

![熔断规则编辑器](/images/console/gov-circuit-breaker.png)

## 操作步骤

1. 「新建规则」→「熔断」。
2. 填写并保存：
   1. **基础信息**：规则名称（kebab-case）、优先级、描述、规则标签
   2. **服务范围** + **熔断粒度**（创建时可改）：服务 / 实例 / 接口
   3. **熔断子规则**（至少 1 条）：
      - **熔断策略**：策略名称 → 接口范围 → 错误判断（返回码 / 时延）→ 触发条件（错误率% / 连续错误数）
      - **恢复策略**：最大剔除比例、熔断时长（>0）、连续成功次数、主动探测开关
      - **熔断后降级**：响应码、响应头、响应体
3. 「发布」。

## 字段注意

| 项 | 说明 |
| --- | --- |
| 粒度 | 仅创建阶段可改 |
| 比例阈值 | 0–100 |
| 默认示例 | 错误率 50%、统计间隔 30、最小请求数 5（以页面默认值为准） |
| 主动探测 | 恢复策略中的开关；主动探测规则本身见 [主动探测](/docs/guides/console/governance/fault-detect) |

## 发布与观察

- 发布资源：`CircuitBreakerRules`
- 观察打开与恢复是否符合条件；降级响应是否符合预期
