向导类型：**无损**（`kind=lossless`）。文档中的「优雅发布 / 优雅上下线」对应本能力；Console 卡片与列表统一称 **无损**。

![无损规则编辑器](/images/console/gov-lossless.png)

## 操作步骤

1. 「新建规则」→「无损」。
2. 填写并保存：
   1. **基础信息**：规则标识、优先级（页面固定展示 **5**）、启用状态、规则标签
   2. **治理对象**：命名空间、服务名称
   3. **无损上线 · 延迟注册**：上线保护启用；策略为时长延迟或探测延迟
   4. **服务预热 · 渐进放量**：预热窗口、终止保护百分比、预热曲线值（1–5）
   5. **无损下线 · 等待时长**：下线保护启用、下线等待间隔
3. 「发布」。

## 三项能力

| 能力 | 关键字段 |
| --- | --- |
| 延迟注册 | 时长 ≥0；或探测协议 HTTP/TCP/UDP + 间隔 >0 |
| 服务预热 | 预热窗口 >0；终止保护百分比 0–100；曲线 1–5 |
| 无损下线 | 下线等待间隔 >0 |

**至少启用一项**能力，否则保存校验失败。启用状态由三项能力推导展示。

## 发布与观察

- 发布资源：`LosslessRules`
- 列表名称常显示为 `命名空间/服务`
- 观察：上线是否延迟摘流/注册、预热是否平滑、下线是否等待完成
