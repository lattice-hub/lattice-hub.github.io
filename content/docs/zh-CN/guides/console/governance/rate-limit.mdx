title: 限流规则
description: 创建本地/集群限流：作用对象、接口匹配、QPS/并发与限流效果。
---

向导类型：**限流**（创建时 kind 为 `ratelimit-local`）。工作台卡片文案为「限流」。

![限流规则编辑器](/images/console/gov-rate-limit.png)

## 操作步骤

1. 「新建规则」→ 选环境 → 点「限流」。
2. 填写并保存：
   1. **基础信息**：规则名称（kebab-case）、优先级、启用状态、规则标签
   2. **作用对象**：命名空间、服务名称、**限流模式**（单机限流 / 集群限流）
   3. **限流规则**（至少 1 条子规则）：
      - 匹配接口（协议 HTTP/HTTPS/gRPC、方法、路径）
      - 匹配条件（可选）
      - 限流方式：请求数(QPS) 或 并发数；窗口秒数 / 最大数量须 >0
      - 限流效果：快速失败 / 排队等待；可配自定义响应（合法 JSON）
3. 「发布」全量或灰度。

## 模式说明

| UI 文案 | 说明 |
| --- | --- |
| 单机限流 | 向导默认创建路径；可排队等待 |
| 集群限流 | 在编辑器「限流模式」切换；**仅支持快速失败** |

页面上还可能出现「本地限流 / 全局限流 / 分布式限流」等列表文案，以编辑器当前模式为准。

## 校验要点

- 至少 1 条限流子规则，且至少 1 个接口、路径非空
- QPS 窗口与并发阈值必须 >0
- 自定义响应须为合法 JSON
- 可选「阈值计算合并」（regex_combine）：按匹配请求合并或单独计算

## 发布与观察

- 发布资源：`RateLimitRules`
- 观察拒绝是否符合阈值；灰度客户端是否命中预期效果
