Thin SDK 是面向 **Pole Sidecar** 的多语言接入层，与 [Rust SDK](/docs/components/rust-sdk) 的 Proxyless 路径不同：应用不直连控制面做完整治理消费，而是通过本机 Sidecar Session 获取 listener，并注入 `TargetService v1` 元信息，由本地 Sidecar 执行治理与转发。

## 契约

契约源在 [specification / thin-sdk](https://github.com/lattice-hub/specification/tree/main/thin-sdk)。当前契约版本为 `2.0.0`：

- Sidecar Session wire v1
- TargetService wire v1（仅 `namespace` + `service`）

旧版 `TargetEnvelope v1`（契约 `1.0.0`）已废弃。默认 bootstrap UDS：`/var/run/pole/sidecar/bootstrap.sock`，可用环境变量 `POLE_SIDECAR_SOCKET` 覆盖。

## 能力边界

- 交付框架无关契约核心：建立 Sidecar Session、接收 listener 快照、编码 TargetService 元信息
- 不绑定具体 HTTP / gRPC / Dubbo 框架 adapter
- 业务流量仍走原协议访问 `127.0.0.1:<listener-port>`，不经过 bootstrap gRPC
- 端到端兼容组合仍按 [compatibility matrix](https://github.com/lattice-hub/specification/blob/main/thin-sdk/compatibility.json) 演进，**不得写成生产就绪**
