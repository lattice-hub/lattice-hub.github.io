Control Plane 是 Lattice Hub 的核心组件。它组织 API、业务逻辑、缓存和存储，向外提供 HTTP、gRPC、xDS、Nacos、Apollo、Eureka 等多协议入口；Console 已合并在同一仓库与部署单元中，不再作为独立组件列出。

![deployment architecture](/diagrams/deployment-architecture.svg)

## 关键职责

- 服务发现：管理命名空间、服务、实例和健康状态。
- 配置中心：支持配置发布、灰度、回滚、SSE 或长轮询监听。
- 治理规则：承载路由、泳道、限流、熔断、故障探测、无损上下线、调用鉴权、流量镜像和流量 Mock。
- AI Native：MCP Registry 与 A2A Agent Registry 已具备存储、缓存、HTTP API 和 Console 管理入口。
- Pole Agent：通过真实 LLM/MCP 最小闭环读取资源，并将配置修改限制在预览、确认和草稿边界内。
- 系统配置与观测：提供 63 项类型化配置目录、OTel 指标出口和共享 GreptimeDB 查询。
- 权限控制：资源支持细粒度鉴权，对标云厂商 CAM/RAM 类型能力。
- 内嵌 Console：Fluent UI 管理界面，覆盖资源、治理、权限、Registry、系统配置与平台监控。

## 内嵌 Console

Console 与 Control Plane 同仓交付，可通过 `--mode all|server|console` 组合部署：

| 模式 | 作用 |
| --- | --- |
| `all` | 控制面 API + 内嵌 Console（本地默认） |
| `server` | 仅控制面 API / 协议入口 |
| `console` | 仅 Console 网关，通过网络访问 `poleServer.address` |

逐步操作见 [控制台使用](/docs/guides/console-use)。界面示例：

## 已确认工程事实

- 技术栈包括 Go、`go-restful/v3`、gRPC、MySQL、`envoyproxy/go-control-plane`、`mark3labs/mcp-go`、OpenTelemetry 与 Pebble；Console 前端为 React 18 + Fluent UI v9。
- 控制面按协议适配层、领域 Server、interceptor、缓存层、存储层装配，而不是单一 HTTP CRUD。
- 缓存层覆盖服务、配置、治理规则和 AI Registry 等资源，后台默认每 1 秒增量刷新。
- 增量查询窗口使用 `lastMtime - 5s` 规避时钟偏差。
