Console 是 Lattice Hub 面向平台团队的操作入口。它和 Control Plane 位于同一仓库，可通过 `all`、`server`、`console` 三种模式部署；`console` 模式只通过网络依赖后端，不直连核心业务表。

逐步操作见 [控制台使用](/docs/guides/console-use)。

## 当前能力

- 管理运行环境、服务、实例与主动健康检查。
- 管理配置分组、文件、灰度发布、历史和回滚。
- 在统一治理工作台查看和编辑路由、泳道、限流、熔断、故障探测、无损上下线、调用鉴权、流量镜像与流量 Mock。
- 管理用户、用户组、角色、策略和受保护的内置角色。
- 管理 MCP Server、A2A Agent Card、技能与后端服务绑定。
- 通过独立 `/agent` 工作模式使用 Pole Agent。
- 浏览 Server / Console 的类型化系统配置、草稿、发布与生效状态。
- 查询基于 OpenTelemetry 与共享 GreptimeDB 的平台监控数据。

## 设计系统

Console 使用 Microsoft Fluent UI React v9：

- 根节点使用 `FluentProvider` 与显式品牌主题。
- 主色使用 Fluent Web Blue（`#0F6CBD`），背景为冷灰，内容表面为白色。
- 页面不使用装饰渐变、发光光斑或大面积深蓝。
- 表格、表单、抽屉、通知、导航和图标操作统一经过仓库级 Fluent 适配边界。
- 亮色和暗色主题共享语义 token。

## Pole Agent

Pole Agent 是 Console 的一等对话主体。它使用版本化 Prompt、OpenAI-compatible LLM Gateway 和白名单 Pole MCP 工具读取资源。配置文件更新必须先生成临时差异，经用户确认后只保存草稿；发布、回滚和删除仍由确定性产品流程承担。

当前 Agent 写路径仅覆盖已有配置文件更新。治理规则写入、服务端会话持久化和流式输出仍在推进。未配置 LLM Gateway / API key 时，`/agent` 不可用，但不影响其余功能。

## 系统配置与安全

Server / Console 已登记 63 项显式配置目录，其中 43 项可以通过页面管理。每个字段都会说明来源与 apply mode：

- `BootstrapOnly`：只能通过部署配置修改。
- `RestartRequired`：可以发布期望值，但实例明确回执 `pending_restart`。
- `HotReload`：只有具备安全 applier 的领域才允许受控热更新。

Agent API key 通过 write-only Secret 管理，配置正文、页面、diff、日志和模型上下文都只看到 SecretReference。
